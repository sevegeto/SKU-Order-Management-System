Developed a web-based order management system using Google Apps Script, HTML, JavaScript, and Google Sheets to streamline order processing for the sales and accounts teams.

The application allows sales representatives to select SKU codes from a dropdown, automatically fetch MOQ and scheme details, validate order quantities, prevent duplicate SKU entries, and submit orders directly to Google Sheets.
Business Problem

Sales representatives were sending orders through emails and spreadsheets, resulting in:

Incorrect SKU codes
Duplicate SKU entries
Orders below MOQ
Delays in order processing
Increased dependency on the accounts team
Solution

Built a centralized order management system that:

Provides SKU dropdown selection
Displays MOQ automatically
Displays applicable schemes
Prevents duplicate SKU selection
Validates order quantities
Captures customer details
Stores orders directly in Google Sheets
Reduces manual intervention
Features

✅ Dynamic SKU dropdown

✅ Auto-fetch MOQ

✅ Auto-fetch Scheme Details

✅ Duplicate SKU Prevention
